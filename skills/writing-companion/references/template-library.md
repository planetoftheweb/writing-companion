## Make a format theirs

1. Read the approved voice, rules, and relevant project. Ask only about missing audience, purpose, length, or required sections, at most three questions per turn.
2. Explain the suggested structure briefly. Remove sections that do not serve this piece; preserve requirements the person already approved.
3. Try an opening or short piece. Treat use of a starter as permission for this draft, not as approval to save lasting guidance.
4. Once confirmed, save the adapted template and custom instructions together in one content-type scope. Record what the person approved. Keep unresolved choices in the checkpoint.

For a format used across projects, use global scope as its parent. For a series-only variation, put the format under that project. A general script and a project's script can coexist with distinct IDs. Never overwrite unrelated formats with the same display name.

## Shared guidance and optional choices

- [Writing foundation](../assets/guidance/writing-foundation.md) contains reusable quality checks.
- [Voice and rules choices](../assets/guidance/voice-options.md) helps someone express preferences without prescribing a personality.
- [Workspace starter](../assets/guidance/workspace.md) is for shared audiences, terminology, and requirements.
- [Series starter](../assets/guidance/series.md) connects a recurring project to separate content formats.

The library is adapted from a creator's six working formats. Personal names, organizations, private project details, exact production quotas, and autobiographical examples were removed. Preferences about enthusiasm, punctuation, paragraph length, hashtags, emojis, links, and closing questions became optional choices. The library retains useful methods: source-supported claims, distinct spoken and written formats, readable structure, and review before learning.

The illustrative AI Model Trends series is an example of a LinkedIn video series, not someone's profile. Its script and companion post can share project context while keeping different structures.
