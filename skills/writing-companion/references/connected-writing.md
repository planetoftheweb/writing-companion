# Optional connected writing workflow

Use this only when the creator chooses to work with a connected writing app. Writing Companion remains usable without a connection. Keep the reusable method separate from private voice, rules, examples and project knowledge; never add private material to the installed skill or its public repository.

## Writaible connection

Discover the tools available in the current session; do not assume an MCP connection exists. Choose the intended shared workspace and document using list_workspaces and get_script. Read get_writing_context for that destination before drafting or reviewing, plus get_writing_guide for the target surface when available. Apply enabled effective voice (including exposed Creator Soul guidance), rules and inherited project instructions. Read actual guidance, not just filenames. Report inaccessible context rather than claiming the full account Soul was loaded.

Treat Writaible as the authority for this connected document. Do not silently merge an older exported profile over current guidance. If an explicit task instruction conflicts, follow its scope; ask only when a material conflict remains unresolved. Re-read guidance at the start of a new writing task and after an approved update. There is no background synchronization.

Learn from edits by proposing at most three lasting lessons. Identify the scope and evidence; distinguish a correction to this piece from a standing preference. Only confirmed lessons may be saved. Existing user authorization to save the exact rule in the exact destination suffices; editing a draft alone does not approve a profile change.

For an approved shared workspace or project update, call get_guidance for the destination, then import_guidance without ifRevision to preview. Inspect the proposed text and preserve unrelated rules. Apply the same text and mode with the preview revision only after authorization; on conflict, re-read and review the changed result instead of overwriting. Default to append, but inspect for an existing equivalent rule so repeated learning does not duplicate it. Verify with get_guidance and get_writing_context. Disabled guidance stays disabled.

Connected assistants cannot modify raw personal account voice or rules. Prepare an account import for the creator to preview and apply inside Writaible if the lesson belongs there. Do not create a project soul.md as a workaround. Shared access and the server's scope restrictions remain authoritative.

Without a connection, use the latest creator-approved portable profile and mark it as a snapshot. Offer a private export for approved updates. Do not claim it was installed, saved in another app, or read by another bot.

## Across assistants

Claude, ChatGPT and Grok Bot can use this workflow only where their current session exposes the required tools. Otherwise supply the Project edition guide and an approved private profile separately. Verify each assistant independently: read the shared method version, load effective guidance for the chosen document, and produce a short visual plus matching narration from a supplied example. Record actual tool results and remaining access gaps. Installing a package does not prove another assistant loaded it.
