# Stay inside the platform

Installation adds the workflow. The creator's profile still needs a durable home. Do not assume the sandbox filesystem or a chat attachment will be available in the next chat.

## Claude

Use the installed Writing Companion skill in the current chat. For recurring work, recommend a private Claude Project containing the latest `writing-profile.md` exported by the companion. Add the short project instructions included in the distribution. The person can also attach their profile ZIP directly in a later chat when file tools are available.

Create downloadable files using the platform's actual file tools. Show native download links. Ask the person to add the latest profile to project knowledge, replacing the old active copy to avoid conflicting versions. Keep the full ZIP privately for history. Do not claim you changed project knowledge unless a supported tool actually did so.

Custom skills can be uploaded as ZIP folders through Customize → Skills. Account controls may require enabling code execution and file creation. [Claude's instructions](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

## ChatGPT

On an eligible account, install the skill through Plugins → Skills → Create → Upload from your computer. Follow the current UI if the labels differ. Skills availability depends on the account and workspace. [ChatGPT's instructions](https://help.openai.com/en/articles/20001066)

When installation is unavailable, use the supplied Project edition: add its instructions to a private Project and upload `writing-companion-guide.md`. This runs the same conversation workflow inside ChatGPT. No external webpage is required.

For continuity, add the latest exported `writing-profile.md` to the Project's sources. Keep one active profile, replacing its predecessor; keep the full ZIP separately for history. If a source-saving control is available, it can retain a response, but do not promise silent updates. [Projects and files](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)

Project-only memory does not reference memories from outside the Project. Work from available samples and ask focused questions when memory is missing. Do not tell someone to weaken their memory settings just to use the companion.

## No file execution

The interview and writing still work. Provide the approved profile as readable sections in the conversation or a native document artifact, with a short pending-work checkpoint. Explain how to save it as a project source. Do not invent a ZIP or download link, claim that an export was validated, or claim that old revisions were preserved when they are unavailable. Offer a structured export when file tools become available.

## Portability

To switch platforms, download the current profile ZIP and attach it in the new platform, or upload `writing-profile.md` as project knowledge. Ask the companion to resume. Export only the creator's approved preferences and intentionally saved checkpoint; do not request a complete account history export.
