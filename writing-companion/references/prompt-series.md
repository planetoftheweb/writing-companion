# A conversation at a time

The ten prompts in [the prompt library](../assets/prompts.json) can be used individually inside Claude or ChatGPT. They do not require skill installation, platform memory, or an account in another app. The distribution also includes numbered plain-text copies in `Prompts`.

Start with the first prompt, or jump to the work you need now. Workspace and series setup are optional. Most people can start, try their voice, and write a real piece before filling in the rest.

| Step | Purpose |
|---|---|
| 1. Start with my writing | Gather representative samples or begin without them |
| 2. Find my voice | Reflect, try an opening, confirm preferences |
| 3. Set my writing rules | Capture explicit requirements and exceptions |
| 4. Define a workspace | Optional shared audience, terminology, and requirements |
| 5. Create a project or series | Optional recurring purpose and related formats |
| 6. Adapt a content format | Choose a starter and customize its instructions |
| 7. Write a real piece | Draft from the available approved guidance |
| 8. Learn from my edits | Review up to three proposals, keep only approved changes |
| 9. Save my profile | Export actual files or a clearly labeled checkpoint |
| 10. Resume my work | Continue from the latest supplied profile |

## When someone asks for a prompt

Read the actual prompt text and return the relevant prompt without silently starting its workflow. If they ask to run it, follow its instructions. Later steps work independently, but cannot recover preferences that are not available. Ask for missing guidance or use a clearly described provisional approach.

The format prompt uses the six starter pairs when accessible. Without the library, it offers a provisional structure instead of claiming to have read the templates. Save and resume prompts describe file-tool limits explicitly; a prompt cannot grant access to prior chats or edit platform memory by itself.

Each prompt is one clean paragraph for copying. Explanations and expected outputs are separate from its copyable text.
