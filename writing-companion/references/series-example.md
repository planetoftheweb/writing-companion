# Example: AI Model Trends

This is a fictional teaching example, not an exported person's profile. Do not adopt these preferences for a user.

**Series:** AI Model Trends, a recurring LinkedIn video series helping professionals decide when an AI model is useful for their work.

**Project guidance:** Each episode explains one practical decision, supports claims with dated sources, and distinguishes tested results from vendor claims. Keep comparisons tied to a task rather than declaring an overall winner.

**Script template:** A recognizable work problem → what changed → a concrete task or demonstration → a limitation → a useful takeaway. Recording notes stay separate from spoken words.

**Script instructions:** Use language that reads naturally aloud. Explain only the technical terms the intended audience needs. Verify current capabilities and prices before including them. Ask the creator for the desired length instead of imposing a universal duration.

**LinkedIn post template:** The useful observation → a short explanation of why it matters → context for the episode. Include a link or discussion question only if requested or established in that creator's guidance.

**LinkedIn instructions:** Write for someone reading the feed. Summarize the episode's value without repeating the entire script. Follow the creator's own preferences about questions, links, hashtags, and length.

Both formats inherit the author's confirmed voice and the series requirements. A correction to an episode's model price stays with that episode; “Always include the test date in this series” becomes project guidance after approval.
