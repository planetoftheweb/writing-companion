# Writing Companion

A skill that helps your AI learn your voice, your work, and what good writing looks like to you. It runs in Claude or ChatGPT as an installed skill, as a Project, or as plain prompts.

**New here? Read [START-HERE.md](START-HERE.md).**

- `Source/writing-companion/` — the editable skill (`SKILL.md` and its references, assets, and scripts)
- `Install/` — ready-to-upload skill and plugin ZIPs
- `Project edition/` — the same workflow for ChatGPT or Claude Projects
- `Prompts/`, `Templates/`, `Guidance starters/` — use them without installing anything
- `Quickstart` (Markdown, Word, PDF), `Verification.md`, `Acceptance scenarios.md`
